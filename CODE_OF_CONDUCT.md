# Code of conduct

## Our standard

Nightlock contributors must make technical collaboration safe, respectful, and productive. Expected behavior includes:

- discussing ideas and code without attacking people;
- giving specific, evidence-based review feedback;
- acknowledging mistakes and correcting them;
- respecting different experience levels, backgrounds, and communication styles;
- protecting private and security-sensitive information;
- focusing public discussion on the project and its users.

Unacceptable behavior includes harassment, threats, discrimination, sexualized conduct, deliberate humiliation, publication of private information, bad-faith disruption, and using security reports as leverage against contributors or users.

## Scope

This policy applies in repository issues, pull requests, reviews, discussions, project communication, and public representation of the project.

## Enforcement

Report conduct concerns privately to the repository owner. Do not use a public issue when a report contains personal or sensitive information. The maintainer may remove content, restrict participation, reject contributions, or ban accounts when necessary to protect the project community.

Enforcement decisions should consider context, severity, repetition, impact, corrective action, and the safety of affected people. Retaliation against a good-faith reporter is prohibited.

## Attribution

This policy uses the intent and enforcement model of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) while keeping project-specific reporting language.
